# Where every supply number came from

Confidence is stated per row in `datasets.csv`. `high` means the figure is published by the
dataset's own authors; `med` means it is a widely reported figure I did not verify against the
release itself; `low` means I derived it (usually samples × an assumed tokens-per-sample) and it
could be wrong by 2x; `planned` means the data does not exist yet and we are committing to
build it.

**A caveat that applies to every row.** Published token counts come from the counter's own
tokenizer. Our Session 2 tokenizer measures Telugu at 1.99 tokens/word on clean Wikipedia and
**3.62 on real corpus text** (`reports/s4_shard_tokens.json`). Until the whole inventory is
re-counted with the production tokenizer, treat supply figures as ±20%, and Indic figures as
biased low.

## Indic

- **Sangraha / IndicLLMSuite** — per-language token table taken directly from the dataset card:
  verified **64,306.1M**, synthetic (translated + romanised) **162,707.9M**, unverified
  **24,307.7M**, total **251,321.0M** across 22 languages. Telugu: 3,706.8 / 11,924.5 / 647.4M.
  Hindi: 12,617.3 / 9,578.7 / 12,348.3M. English inside "verified" is 12,759.9M and is removed
  from the Indic supply figure. CC-BY-4.0.
  https://huggingface.co/datasets/ai4bharat/sangraha · https://arxiv.org/abs/2403.06350
- **IndicAlign** — 74.7M prompt-response pairs across the Instruct/Toxic/Anudesh splits. Token
  figure (22B) is derived at ~300 tokens/pair; `low` confidence.
- **IndicCorp v2** — 20.9B tokens, 24 languages; overlap with Sangraha Unverified set at 0.60.
  https://arxiv.org/abs/2212.05409
- **Our Session 4 shard** — 50,867 docs / 15.4M words / **50.0M tokens measured**, not
  estimated (`scripts/measure_s4_shard.py`, 600-doc reservoir sample per language). Subset of
  Sangraha `verified/tel`, so `overlap_frac = 1.00`.

## Web

- **Nemotron-CC** — 6.3T total, **4.4T unique real** plus 1.9T synthetic rephrasings; ~4x the
  unique tokens of DCLM/FineWeb-Edu, which are ~80% fuzzy duplicates.
  https://arxiv.org/abs/2412.02595
- **DCLM-baseline** — 3.8T total / **1.0T unique**. https://arxiv.org/abs/2406.11794
- **FineWeb-Edu** — 1.3T total / **0.2T unique**.

## Code

- **The Stack v2** — 67.5TB, 600+ languages; the commonly cited figure for the near-dedup
  permissive slice is ~900B tokens (`med` confidence — the paper reports bytes and file counts,
  not a single token number). StarCoder2 trained on 3.3–4.3T tokens from it *with repetition*,
  which is consistent with a unique pool well under 1T. https://arxiv.org/abs/2402.19173
- `keep_frac = 0.70` reflects StarCoder2-style quality filtering.

## Reasoning

All token figures here are `low` confidence: the releases publish sample counts, not tokens.

- **Llama-Nemotron Post-Training** — 3.9M samples with R1 traces; 12B assumed at ~3.1k tok/sample.
- **OpenThoughts3-1.2M** — 850k math + 250k code + 100k science, QwQ-32B traces.
  https://arxiv.org/abs/2506.04178
- **AM-DeepSeek-R1-Distill-1.4M** — 900k distilled from R1-671B + 500k cleaned.
- **OpenR1-Math-220k**, **s1K/LIMO** (tiny, Tier A).

## Agentic

- **SWE-ZERO-12M-trajectories** — **12.3M trajectories / 112B tokens** over 122,908 PRs and
  3,222 repos, Apache-2.0. Generated by sampling 100 rollouts per PR from a **1.7B** code model
  at temperature 1.0, **fully execution-free**: no container built, no test run, no verifier.
  5.7x larger than the previous biggest agent-trace corpus (AgentTrove, 19.41B).
  https://huggingface.co/datasets/AlienKevin/SWE-ZERO-12M-trajectories
- **NVIDIA SWE-Zero** 8.92B · **mini-coder** 5.26B · **Open-SWE-Traces** 207,489 trajectories
  (https://arxiv.org/abs/2606.16038) — token figure derived, `low`.
- **SWE-Gym** — 2.4k real tasks with runnable environments (+234 Lite).
  https://arxiv.org/abs/2412.21139 · **R2E-Gym** https://arxiv.org/abs/2504.07164
- **Function calling** — xLAM-60k (**CC-BY-NC-4.0, excluded from production**),
  glaive-function-calling-v2 112,960 samples, ToolACE 11.3k, APIGen-MT-5k, When2Call 15k,
  BUTTONInstruct 8k. Large sample counts, ~0.25B tokens between them.

## Method references

- **Repetition caps** — Muennighoff et al. 2023, *Scaling Data-Constrained Language Models*:
  up to ~4 epochs is nearly as good as fresh data, and returns collapse after.
  https://arxiv.org/abs/2305.16264
- **Selection scoring** — the proxy harness implements RHO-loss style learnability scoring
  (Mindermann et al. 2022, *Prioritized Training on Points that are Learnable, Worth Learning,
  and Not Yet Learnt*) as a stand-in for OPUS's proxy-direction utility estimate.
  https://arxiv.org/abs/2206.07137
- **V4 facts** (OPUS keeping ~40% of candidates for a ~6x effective-token multiplier at a few
  percent overhead; the 8% always-on Indic lane; the ~150x gradient-norm event from a Hindi
  share jump into frozen embeddings; the 70%→18% web / 13%→35% code / 7%→39% science-and-maths
  growth-stage trajectory) are taken from the Session 5 course material.
