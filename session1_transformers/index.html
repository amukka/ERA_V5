S1·1

Activations exist for a reason

Claim. A model with no nonlinearity can only draw a straight boundary, so it cannot separate two concentric rings. Add a single ReLU hidden layer and it can.

Build. 300 noisy 2-D points — an inner ring (class 0) and an outer ring (class 1), not linearly separable. Train (a) Linear(2→1) → sigmoid and (b) Linear(2→16) → ReLU → Linear(16→1) → sigmoid. Only the activation differs.

The linear model is a straight line stuck near 50% — it literally cannot bend around a ring. The ReLU model wraps the ring to ~99%. Same data, same optimizer, same everything — the only change is one activation function.

S1·2

Depth without nonlinearity is a lie

Claim. Five stacked linear layers collapse to a single linear map, so a 5-layer linear net is no stronger than 1 layer. Both fail the ring identically; inserting ReLUs between the same five layers suddenly solves it.

Build. Same rings. Train 1 linear layer, 5 linear layers (no activation), then 5 layers + ReLU — then multiply the five weight matrices numerically to expose the collapse.

The 1-layer and 5-linear-layer boundaries are the same straight line at the same accuracy — depth added nothing. Multiplying the five weight matrices proves why: they reduce to one 2×1 matrix. ReLU between the layers is what breaks the tie.

S1·3

Embeddings learn similarity from nothing but next-token

Claim. Trained only to predict the next token in a tiny synthetic grammar, the embedding table clusters related tokens — though similarity was never supplied as a label.

Build. A toy language with categories and templates, so same-category tokens share next-token distributions. Train a tiny embedding → softmax next-token model, then project the learned 8-D embeddings to 2-D with PCA.

S1·4

Memorization vs generalization — and data closes the gap

Claim. A high-capacity model on tiny data drives train loss to ~0 while held-out loss stays high. Growing the dataset closes the gap.

Build. A learnable noisy 2-class problem (two interleaving moons) with a fixed held-out test set. Train the same over-parameterized net 2→48→48→1 at train sizes 20, 200, 1000.
