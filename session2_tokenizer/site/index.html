Faithful roundtrip gate

The grading gate: a tokenizer is only accepted if decode(encode(text)) returns the same text. Because this is byte-level BPE, every token is an exact byte string and decoding concatenates them — so the roundtrip is lossless for any input, including whitespace. Verified live below.

How the 10k budget is split. English is given the minimum merges to reach fertility ≤ 1.2 (the assignment's English constraint); adding the other languages' merges only lowers it further, so the cap always holds. The remaining budget is water-filled across Hindi, Telugu and Kannada to pull their fertilities down to the lowest common level the budget allows — minimizing the max−min gap that drives the score.

Word & fertility definition. A “word” is a whitespace-delimited token (len(text.split())); fertility = len(encode(text)) / words. This is byte-level BPE: base = 256 bytes, so decode(encode(text)) == text losslessly for any input. Fertility is measured on these pinned pages only.
